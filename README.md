# Node Attack Online

A multiplayer-ready web version based on the supplied working Node Attack HTML.

## Run

1. Install Node.js 20+.
2. `npm install`
3. `npm run dev`
4. Open `http://localhost:5173` in two browser tabs.
5. Select **Node Attack → Online Multiplayer**. Create a room in one tab and join its code in the other.

The current online implementation supports two players, synchronized turns, scoring, discards, rematches, and server-side move validation.
